## 191 - 3.8
- Shortcuts (Tools): pin apps, hidden activities, app long-press shortcuts, files, folders, photos, links and commands to your home screen.
- Button Remapper (Tools): choose what holding the power button does, including custom actions like the flashlight or a screenshot.
- APK Icon Changer and APK Extractor (Tools): change an installed app's icon, or save any app's APK to Download/CustomAnimator.
- WhatsApp Cleaner (Optimizer): delete old WhatsApp media and backups by category and age.
- OTP Copier (Tools): verification codes in notifications are copied automatically.
- Save on device (Tools): share anything to this app to save it to a folder or copy it.
- Notification Filters (Notifications): filters can now remove matching notifications; rules, filters and history are on one screen.
- Screenshot actions (Tools): delete now moves the screenshot to the system trash with no confirmation dialog (Android 11+).
- Game Mode: new Excluded list for apps that should keep running. Profiles can run shell commands, and icon pickers now offer 1,150+ icons.
- Faster app lists and Debloater, less background work, smaller app. Fixed black bars with per-app width, the keyboard covering content and Back navigation.

## 190 - 3.7
- Per-app features (Auto Force-Stop, Permission Disabler, per-app width, refresh rate and threading) no longer need Usage Access — the foreground app is now detected through Shizuku, instantly and without polling.
- Optimizer: new Exclusion List for apps that Close Background Apps and Performance Booster should never force-stop, confirmation before closing apps or clearing caches, and a count of closed apps.
- Screenshot notifications can now dismiss themselves automatically after a delay you choose.
- Carrier name changes are more reliable.
- Fewer ads: full-screen ads are limited to 2 per day, at least 20 minutes apart; if no rewarded ad is available, the feature unlocks for free.
- Force GPU rendering removed from HWUI tweaks, as it has no effect on current Android versions.
- Fixes: more accurate smallest width values, and Quick Settings tiles update as soon as Shizuku connects.

## 189 - 3.6
- Debloater (Tools): list every preinstalled app and remove, disable or restore it for this user — with risk levels, protection for critical system apps, APK export and one-tap Restore all.
- Optional community package list: download the Universal Debloater Alliance list for more detailed descriptions and risk ratings.
- Battery Health (Battery tab): see capacity, cycles, temperature, current and Doze details.
- Shizuku status is now tracked in one place, so permission state stays fresh on every screen.
- App-open ads removed: no more full-screen ad when you open the app.

## 186 - 3.5
- Status Bar Icon Manager (Tools): toggle 40+ icons — clock, battery, Wi-Fi, hotspot, NFC and more — grouped by Status, Connectivity, Sound and System, with Show all / Hide all.
- New Optimizer tab (replaces Boost & Cleaner): Cleaner frees space and memory in one tap, Performance Booster does a deeper step-by-step tune-up — now in one screen.
- Rebuilt Quick Settings tiles: Placed vs. Add a tile lists, expandable categories with counts, advanced options and a simpler custom toggle builder; new Restart System UI tile, Sound tile now managed here.
- Smoother navigation: HomeTopBar extracted, ExpressiveNavBar refreshed and animation preview re-timed for less jank.
- More reliable tiles & permissions: all tiles share BaseTileService and Shizuku now uses awaitShizukuPermission for stable binder handling.
- More reliable hotspot: turning the hotspot on/off and changing its settings now works more consistently, especially on newer Android versions.
