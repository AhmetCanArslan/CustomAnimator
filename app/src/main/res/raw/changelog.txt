## 189 - 3.6
- Debloater (Tools): list every preinstalled app and remove, disable or restore it for this user — with risk levels, protection for critical system apps, APK export and one-tap Restore all.
- Optional community package list: download the Universal Debloater Alliance list for more detailed descriptions and risk ratings.
- Battery Health (Battery tab): see capacity, cycles, temperature, current and Doze details.
- Shizuku status is now tracked in one place, so permission state stays fresh on every screen.
- App-open ads removed: no more full-screen ad when you open the app.

## 186 - 3.5
- Status Bar Icon Manager (Tools): toggle 40+ icons — clock, battery, Wi-Fi, hotspot, NFC and more — grouped by Status, Connectivity, Sound and System, with Show all / Hide all.
- New Optimizer tab (replaces Boost & Cleaner): Cleaner frees space and memory in one tap, Performance Booster does a deeper step-by-step tune-up — now in one screen.
- Rebuilt Quick Settings tiles: Placed vs. Add a tile lists, expandable categories with counts, advanced options and a simpler custom toggle builder; new Restart System UI tile, Sound tile now managed here.
- Smoother navigation: HomeTopBar extracted, ExpressiveNavBar refreshed and animation preview re-timed for less jank.
- More reliable tiles & permissions: all tiles share BaseTileService and Shizuku now uses awaitShizukuPermission for stable binder handling.
- More reliable hotspot: turning the hotspot on/off and changing its settings now works more consistently, especially on newer Android versions.
