# v2.0 (v1.6'dan beri)

## Yeni Özellikler
- **Developer Options** ekranı: ADB (USB/Wireless) debugging, "Don't Keep Activities" ve "Limit Background Processes" toggle'ları
- **Auto Force-Stop**: seçilen uygulamalar arka plana düşer düşmez otomatik force-stop edilir (arka planda servis olarak çalışır)
- **Auto Permission Disabler**: seçilen uygulamaların izinleri arka plana düşünce otomatik iptal edilir, tekrar açılınca geri yüklenir
- **Compile Booster**: tüm yüklü uygulamaları AOT olarak derleyip açılış/performansı hızlandıran araç, ilerleme takibiyle
- **Graphics API Override**: uygulama bazında ANGLE/Native grafik sürücüsü seçimi
- **Width Preset** yönetimi: "smallest width" (dp) için kayıtlı presetler
